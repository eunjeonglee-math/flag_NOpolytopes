Five additional affine unimodular equivalences

The 28 classes reported in BLMM, Proposition 4.8 and Table 6, reduce to 23 after these five additional identifications. S1, …, S31 below are the labels of that table.

Coordinate convention: y = Ax + b in unshifted, ten-dimensional string coordinates from the original notebook. The coordinates x₁, …, x₁₀ and y₁, …, y₁₀ follow the source and target reduced words shown below. These are not the centered cluster coordinates in the seed browser, nor the raw 14-dimensional coordinates in the BLMM data export.

The maps were verified on complete vertex sets at ρ. At 2ρ, A is unchanged and b is doubled. The weight selector changes only this reference page; the seed browser uses 2ρ.
