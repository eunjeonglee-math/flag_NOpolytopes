How to read this wiring

Read the crossings from left to right: sᵢ exchanges levels i and i + 1, counted from the bottom. Each numbered chamber gives a flag minor ΔI. Hover or focus to see I and highlight the corresponding row of B.

Bounded chambers are mutable circles; chambers open on the right are frozen squares. Unnumbered left boundary minors specialize to 1. Arrows follow consecutive and interlacing chamber endpoints, with i → j meaning bᵢⱼ < 0.

            REDUCED-WORD SEED

            
Browser convention: root 1 is long and root 2 is short. This marker identifies the chamber seed itself, not just its polytope type.

            
B₂ ↔ C₂ numbering. Cho–Fujita–Lee use C₂ root 1 short and root 2 long. Exchange the simple-root labels 1 ↔ 2: browser [1,2,1,2] ↔ C₂ [2,1,2,1] (Seed 0), and browser [2,1,2,1] ↔ C₂ [1,2,1,2] (Seed 3). The order of positions is unchanged; mutation directions are quiver labels and are not swapped by this convention. Weight coefficients (a,b) become (b,a); the browser weight 2ρ is unchanged. The string inequalities agree exactly after the coordinate change. See Cho–Fujita–Lee, Theorem 3.5 and Lemma 5.17.

To use the example below with individual downloads, place the JSON files in docs/data/verification/ under your working folder.

          
Read the saved results without rerunning the computation. From the repository root, use Python or SageMath:

          
import json
from pathlib import Path

kind = "A4"  # A3, A4 or B2
data = json.loads(Path(f"docs/data/verification/{kind}_verification.json").read_text())
seed_id = 0
seed = data["seeds"][seed_id]
seed["B"], seed["H"]

          
H rows mean c + a · x ≥ 0. Class memberships are in data["combinatorial"]["groups"] and data["affine_unimodular"]["groups"].
